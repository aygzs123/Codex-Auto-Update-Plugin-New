# Codex Updater 交互设计稿

设计评审稿 v1.1 · 2026-11-10

## 打开方式

双击 `index.html`，使用 Edge 或 Chrome 打开。单个 HTML 已包含样式、图标和交互，无需联网或安装依赖。

## 建议体验

1. 查看左侧 mac 装饰圆点和右侧窗口按钮，体验概览中的下载与安装流程。
2. 进入“诊断”，点击常驻的“修复资源”。正常状态也可以执行。
3. 进入“设置 → 外观”，切换浅色、深色和跟随系统，刷新后检查是否记住选择。
4. 进入“版本与缓存”，点击底部“模拟外部删除缓存”，观察列表和空间变化。
5. 进入“设置 → 存储”，体验缓存迁移和应用迁移条件检测。
6. 用底部场景切换查看网络失败、资源异常、签名失败、取消授权和不支持迁移。

“重置演示”恢复初始数据及偏好。底部演示工具只用于评审，不属于正式产品。

## 使用边界

这份原型可直接提供给同事评审，不是已修复并发布的桌面应用。数据、进度、安装、修复、磁盘清理及迁移均为演示，不修改电脑。主题和设置开关仅保存在当前浏览器。

Windows 支持有条件的应用包迁移，但当前 Codex 包能否迁移，需要桌面端检测和实机验证。不要直接移动 WindowsApps 文件夹；用户数据与项目文件也不保证随应用迁移。
