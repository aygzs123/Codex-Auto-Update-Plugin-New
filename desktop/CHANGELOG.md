# Changelog

本文件是 Codex Updater 更新公告的唯一来源：

- 应用内「更新公告」读取这里的历史小节；
- 发布工作流把当前版本的小节作为 GitHub Release 正文。

每次发版前必须在本文件最上面写一条 `## [版本] - 日期`，否则发布流程会失败。
正文里不要写「未签名 / SmartScreen」这类固定说明，发布工作流会统一追加。

## [0.5.2] - 2026-11-10

### 改进

- 缓存直接使用所选盘符和文件夹，不再自动追加固定子目录。支持迁移已有安装包、只切换下载位置，以及在确认前重新选择文件夹。
- Codex 应用迁移新增文件夹选择入口，同时展示所选位置和 Windows 实际应用存储位置。MSIX 仍由系统管理，不能直接安装进任意子文件夹；不可用的目标会说明原因。
- 精简存储页说明，区分应用、安装包缓存和用户数据的迁移范围。诊断页的手动修复入口继续保留。

### 修复

- 修复空缓存或缓存目录尚未创建时无法更换位置的问题；选择目录后须确认才保存，取消不会修改设置。
- 修复迁移预检失败后仍显示旧目标、非法路径阻塞后续迁移的问题，并拒绝通过目录联接指向原缓存的目标。
- 强化迁移文件保护：不覆盖预检后出现的同名文件，清理前再次校验源文件与目标副本，发生变化的文件保留并报告。
- 排除离线应用卷，执行应用迁移前重新验证所选目录；取消管理员授权显示为正常取消，其他提权错误仍报告失败。
- 诊断信息按实际设置显示缓存保留策略，不再固定写成“不自动清理”。

## [0.5.1] - 2026-11-10

### 改进

- 安装包瘦身：只保留中英文语言包（去掉 40 余个其它语系），并启用最高压缩级别。安装包从 93MB 降到 82MB，安装后占用从 327MB 降到 286MB。功能与界面不变。

## [0.5.0] - 2026-11-10

### 新增

- 设置页拆成四个标签：通用 / 外观 / 存储 / 关于。
- 新增「设置 → 存储」：显示缓存目录与实际安装卷所在的磁盘、总容量与可用空间；目标盘装不下时会拒绝迁移并说明原因。
- 缓存目录可以换到任意文件夹：新位置固定是所选文件夹下的 `Codex Updater\downloads`，确认块里可以选择是否把现有安装包一起搬过去。搬的话分块复制、两端 SHA-256 校验通过才切换目录，最后清理源目录；不搬就只切换设置。目标位置已有同名文件时不覆盖；取消或失败都保留原目录与设置。
- 新增 Codex 本体迁移：用 `Get-AppxVolume` / `Get-AppxPackage` 检测包是否可移动，列出可选的 AppxVolume；经确认后在系统 UAC 提权里执行 `Move-AppxPackage`。不复制 WindowsApps、不改所有权、不建目录联接，用户数据目录不随之迁移。

### 改进

- 主题改为跟随系统 / 浅色 / 深色三档，切换立即生效并写入设置；启动首帧按保存的偏好上色，不再先闪白再变深。
- 诊断页的修复入口改为先确认：说明修复范围（只重建资源副本，不动配置与会话）、会关闭 Codex，默认焦点停在「取消」；未安装 Codex 时入口保留但禁用并说明原因。
- 版本历史与缓存卡片补充读取状态：正在读取、读取失败与空缓存分别显示，避免空白被误认为「没有安装包」。
- 更新公告改为按版本列出「这次改了什么」：版本、日期和逐条说明，不再出现发布平台字样，也不再放外链。
- 迁移类操作加入关窗保护：迁移进行中关闭窗口会先确认，不会留下中断的中间态。
- 存储页的每个设置块改成独立卡片，缓存 / 应用本体 / 用户数据各自成组，不再是贴在卡片边缘的一条条分隔线。
- 设置文案整体精简：说明只留操作后果和限制，不再复述界面已有的信息。

### 修复

- 修复重新检测迁移条件后目标卷下拉框仍保留旧值、点「迁移到所选卷」没有反应的问题：选择器改为受控值，候选卷变化时自动对齐。
- 修复能力检测块里「可以尝试迁移」与版本号粘连在一起的问题。
- 「检测迁移条件」按钮下方补一行状态（尚未检测 / 正在检测 / 检测完成 · HH:MM）；有命令正在执行时会直接说明，不再点了毫无反馈。
- 修复存储页「用户数据」卡片说明文字贴着卡片底边、与其它设置块不对齐的问题。
- 设置里的下拉框改用一笔 SVG 折线箭头，替换原来两个渐变方块拼出的 V（缩放或深色下边缘发虚）。
- 修复设置说明里的加粗文字被当成整段独占一行、把一句话拆成三行的问题。
- 迁移确认块的信息改为两列网格，当前目录、安装包数量、目标可用空间不再挤成一行。

## [0.4.0] - 2026-11-10

### 新增

- 更新器自更新支持重试与断点续传：下载中断后自动重试最多 3 次，已下载的部分用 HTTP Range 接着下；进度行给出百分比、已下载 / 总量、平均速度与剩余时间。
- 设置 → 更新与通知：自动检查、发现新版本后自动下载（只放进缓存，不安装）、系统通知、后台复查间隔（1 / 3 / 6 / 12 / 24 小时）。
- 设置 → 外观：主题颜色（跟随系统 / 浅色 / 深色），切换立即生效，原生窗口底色与托盘菜单一起变。
- 设置 → 网络诊断：一次探测 GitHub API、更新包下载与分发源三条路径，显示当前代理规则、延迟与失败原因。
- 版本历史支持逐包管理：单独校验签名、固定（固定后不被自动剪枝）、删除（原生确认框，默认「取消」）。
- 设置 → 安装包缓存：自动保留份数（不自动清理 / 保留 2、3、5、10 个）。
- 托盘与任务栏角标：有可装的新版本时显示红点，下载中在提示里写「正在下载更新包」。

### 改进

- 自动下载完成后再弹一条系统通知，说明安装包已经就绪。
- 概览页的「本次更新后无法退回当前版本」常驻告警已移除：保留策略现在是设置项，版本历史里也能逐包固定或删除。

### 修复

- 修复从 PowerShell 7 终端启动时，修复资源副本与签名校验报「无法将 Get-FileHash 项识别为 cmdlet」的问题：脚本环境补回 Windows PowerShell 5.1 的模块目录，SHA-256 改走 .NET 实现，不再依赖命令自动加载。

## [0.3.0] - 2026-11-10

### 新增

- 设置 → 关于可以直接检查更新：发现新版本后在应用内下载，校验 SHA-256 后静默安装，装完自动重启。
- 顶栏新增更新公告铃铛：有更新器新版本时亮红点，按时间线展示历次发布说明，可逐条忽略。

### 改进

- 顶栏左侧改回 mac 的三颗彩色圆点，最小化 / 最大化 / 关闭固定在右侧。
- 关于页把当前版本放大成主角，检查完直接给出「已是最新 / 可更新到」的状态徽章，按钮跟着状态换文案。
- 侧栏不再重复产品名；首次打开按内容尺寸展开，不需要手动拉伸。
- 版本结论集中在主区仪表；安装位置等长路径完整换行显示。
- 去掉「非官方工具 · 与 OpenAI 无关」等不准确表述。

### 修复

- 修复主屏与副屏缩放比不同时，窗口按错误尺寸打开、界面只剩一窄条的问题。
- 修复启动阶段主区在两段中间态没有任何说明的问题。

## [0.2.0] - 2026-11-09

### 变更

- 界面重构为侧栏工作台：概览 / 诊断 / 版本历史 / 设置四个入口。
- 去掉 Electron 默认的 File / Edit 菜单，只保留最小化 / 最大化 / 关闭。
- 版本状态收进主区，顶栏不再重复状态胶囊。

## [0.1.0] - 2026-10-03

### 首个版本

- 一键检查、下载、校验发布者签名并安装 Codex Desktop。
- 支持从本地缓存回退到旧版本；安装包缓存不再自动删除。
- 健康自检：五个资源副本 + 窗口探测，可一键修复。
- 启动时静默检查更新，后台每 6 小时复查。
- 安装需要管理员权限时按需提权，自动化流程改为如实报告。
